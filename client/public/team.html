Architecture Alignment

Vanilla HTML5/CSS3/JS Public Layer + Hexagonal Backend

Public pages (Home, Project Overview, and Team) are authored directly in semantic HTML5, external CSS3 stylesheets, and modular Vanilla JavaScript using Fetch JSON APIs, integrated with the React campus workspace over one shared Node.js + Express + PostgreSQL Hexagonal Architecture backend.
